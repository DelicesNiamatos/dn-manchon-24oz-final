# Délices Niamatos — Espace conception & tests

Site interne pour l'équipe **conception, tests de produits et emballages**.

**Adresse publiée :** https://delicesniamatos.github.io/dn-manchon-24oz-final/

## Contenu

| Fichier | Description |
|---|---|
| `index.html` | Page d'accueil collaborateurs — ressources, mockup intégré, protocole de revue |
| `mockup-3d.html` | Maquette 3D interactive du manchon barquette 24 oz |

Fichiers **entièrement autonomes** : aucune dépendance, aucun build, aucune installation.
Ils doivent rester **à la racine du dépôt**, côte à côte (`index.html` charge `mockup-3d.html`).

## Mockup 3D — utilisation

- **Glisser** sur la maquette pour la faire pivoter librement
- **Angles prédéfinis** : héros ¾, le plat, dessus à plat, infos (dessous), arrière, duo empilé
- **Zoom** et **rotation automatique** dans la barre de contrôle
- La zone photo du plat accepte une image par glisser-déposer

## Configuration GitHub Pages

**Settings → Pages → Source :** `Deploy from a branch` — **Branch :** `main` — **Folder :** `/ (root)`

⚠️ Si le dépôt est public, le site l'est aussi. Les fiches techniques restent protégées
(elles vivent sur le Google Site interne), mais la maquette et le protocole seraient visibles de tous.
